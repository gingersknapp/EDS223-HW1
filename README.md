# EDS223-HW1: Environmental Justice Screening
This repository houses materials for HW1 for UCSB's Masters of Enviornmental Data Science course EDS223.  

This project maps proximity to a Superfund site and the percent population of people of color in San Francisco to investigate potential environment injustice.

## Data access
Data was initally accessed from the U.S. Environmental Agency's EJScreen (Environmental Justicice Screening and Mapping Tool).  The EPA does not currently support the tool, but an unofficial version can be found [here](https://pedp-ejscreen.azurewebsites.net/)
